## 🎯 Objetivos

Al terminar el módulo serás capaz de:

- Entender qué es un **algoritmo** y resolver problemas paso a paso.
- Representar la lógica con **pseudocódigo** y **diagramas de flujo**.
- Usar **variables, tipos de datos y operadores**.
- Controlar el flujo del programa con **condicionales y bucles**.
- Organizar el código con **funciones**.
- Trabajar con **listas/arrays** y estructuras de datos básicas.
- **Depurar** y probar tus programas.
- Usar **Git y GitHub** para guardar y entregar tu trabajo.

## 🚀 Cómo empezar

1. **Clona** el repositorio:
   ```bash
   git clone [URL-DEL-REPOSITORIO]
   cd fundamentos-programacion
   ```
2. Crea una **rama** o carpeta personal para tus ejercicios.
3. Realiza los ejercicios de cada unidad.
4. Guarda tus cambios y súbelos:
   ```bash
   git add .
   git commit -m "Ejercicios unidad 1"
   git push
   ```

## ✅ Normas de entrega

- Entrega tus trabajos en la fecha indicada.
- El código debe ser **legible**: nombres claros y comentarios útiles.
- Cada ejercicio, en su carpeta y con un nombre descriptivo (`ej01_suma.py`).
- Trabajo copiado = **suspenso**. Pregunta, colabora y aprende, pero escribe tu propio código.
